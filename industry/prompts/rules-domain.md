【Reglas de traducción y terminología — esta plataforma cubre tecnología, negocios, energía y electromovilidad para lectores de México y Latinoamérica; cumplir estrictamente】

1. Términos con doble sentido: tradúcelos según el contexto. Usa estas equivalencias en notas de IA o software; en electricidad, "transformer" es "transformador", y en negocios, "agent" puede ser "agente comercial".
   - LLM = modelo de lenguaje grande (nunca "maestría en derecho")
   - Token / tokens = token (se deja en inglés; nunca "ficha" ni "moneda")
   - Transformer = arquitectura Transformer (en inglés; nunca "transformador")
   - Agent / Agentic = agente de IA / agéntico (nunca "agente comercial" ni "intermediario")
   - Inference = inferencia; Reasoning = razonamiento (reasoning model = modelo de razonamiento)
   - Fine-tuning = ajuste fino; Pretraining = preentrenamiento; Embedding = embedding o vector de representación
   - Hallucination = alucinación del modelo; Context window = ventana de contexto; Prompt = prompt (en cursivas no hace falta)
   - Cloud = nube; Chip / Semiconductor = chip / semiconductor; Smartphone = smartphone o teléfono inteligente
   - Breach = filtración o brecha de datos; Ransomware, phishing y malware se dejan en inglés
   - Funding round = ronda de inversión; Series A/B = Serie A/B; Unicorn = unicornio; Layoffs = despidos o recortes
   - Gaming = videojuegos; Console = consola; Early access = acceso anticipado

   - En energía distingue potencia (kW, MW, GW) de energía (kWh, MWh, GWh). Distingue híbridos, híbridos enchufables y eléctricos de batería; no conviertas potencia de recarga en capacidad de batería. Conserva la moneda original también al resumir fuentes en portugués.

2. Se conservan en su forma original, sin traducir ni agregar explicación entre paréntesis:
   - Empresas: OpenAI, Anthropic, Google, Meta, Microsoft, Apple, Amazon, NVIDIA, Samsung, xAI, Mistral, DeepSeek, Mercado Libre, Nubank, Rappi, Kavak, Clip, Bitso, Globant, América Móvil, Telcel, Totalplay y similares.
   - Familias de modelos y productos: GPT, Claude, Gemini, Llama, Qwen, Grok, iPhone, Galaxy, PlayStation, Xbox, Switch, Windows, Android, iOS. Regla general: todo nombre de modelo, producto o nombre clave queda en su forma original.
   - Versiones: GPT-5, Claude 4.7, iPhone 18 Pro, Galaxy S26, iOS 26. Regla: el número de versión no se toca, incluidos sufijos como 4o, 405B, V4, R1, Pro, Ultra; nunca conviertas "405B" en "405 mil millones" ni "V4" en "cuarta generación".
   - Siglas técnicas: LLM, RAG, API, SDK, GPU, TPU, NPU, 5G, IoT, SaaS, MCP, AGI, VPN, 2FA. Regla: siglas de 2 a 5 letras mayúsculas se quedan en inglés.
   - Herramientas y plataformas: Cursor, Copilot, Codex, Claude Code, Ollama, Hugging Face, GitHub, AWS, Azure, Steam.

3. Instituciones de la región: usa su nombre oficial en español y la sigla la primera vez si el original la da (por ejemplo, la Agencia de Transformación Digital y Telecomunicaciones, ATDT; la Comisión Federal de Competencia Económica, Cofece; el Banco de México, Banxico).

4. Código, comandos, URL y cifras se copian sin cambios:
   - Código entre comillas invertidas `code` no se traduce; comandos como /code-review, pip install o npm run tampoco.
   - Las URL se dejan igual.
   - Cifras con unidad: 8k de contexto, 175B parámetros, 3.5x más rápido, 3 dólares por millón de tokens, 99.9 %.
   - Montos, cantidades, porcentajes y rangos conservan los números arábigos y la unidad del original; no conviertas monedas ni redondees. Usa punto decimal y coma de miles como en México (1,250.5 millones).

5. Comillas: cuando haga falta citar un nombre o una frase, usa solo comillas rectas dobles ("Para ti"); nunca comillas angulares (« ») ni tipográficas (“ ”).
