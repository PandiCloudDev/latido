# Reporte de problemas de seguridad

Si encuentras una forma de saltarse permisos, una filtración de claves, una inyección o cualquier otro problema que pueda afectar la seguridad de un despliegue, repórtalo de forma privada mediante el [reporte privado de vulnerabilidades de GitHub](https://github.com/PandiCloudDev/latido/security/advisories/new) o escribiendo a monitor@pandi.cloud.

Incluye:

- El commit afectado, el método de despliegue y la información de entorno necesaria;
- Los pasos mínimos para reproducir el problema en un entorno donde tengas permiso de probar;
- El impacto posible, con registros o capturas sin información sensible.

No publiques detalles explotables en issues ni en PR públicos, ni subas claves, contraseñas, cookies, datos de usuarios o bases completas reales. Las dudas de uso y los errores que no son de seguridad van en [Issues](https://github.com/PandiCloudDev/latido/issues/new/choose).

Los problemas de seguridad se verifican y corrigen sobre el `main` más reciente; no hay ramas de soporte de largo plazo. El mantenedor confirmará el alcance, preparará la corrección y publicará una nota cuando corresponda, sin un tiempo de respuesta fijo comprometido. Si el problema está en el motor original, también se notificará al proyecto [AIHOT](https://github.com/KKKKhazix/AIHOT).
